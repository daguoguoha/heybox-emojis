# 小黑盒表情包

按截图顺序整理的 60 张 PNG 静态表情和 40 个 GIF 动图。

[下载完整压缩包](heybox-emojis-60png-40gif.zip)

- [PNG 静态版](PNG静态版_60个)：共 60 张，其中 59 张为透明背景。
- [GIF 动图版](GIF动图版)：共 40 个多帧 GIF，保留原文件和动画。
- 文件名前的序号对应截图位置，便于查找同一表情的静态版和动图版。
- `01_真实手势_截图裁切.png` 未找到原文件，使用截图中的 44×44 原尺寸裁切并保留背景。
- 静态图与动图中的某一帧可能存在姿态差异。

![全部 60 项静态表情预览](表情预览.png)
